経営課題提出フォームの使い方ページ（/help/issues）で表示するスクリーンショットを、
このフォルダに以下のファイル名で保存してください（PNG推奨）。

  issue-format.png   … ③イベント・形式の選択画面
  issue-profile.png  … ④プロフィール入力画面
  issue-input.png    … ⑤入力・AI解析（テキスト形式の例）
  issue-edit.png     … ⑥内容の確認・編集画面

※ 未設置の間は、該当画像は自動で非表示になり、説明文のみ表示されます。
※ 差し替えは同じファイル名で上書きし、git add / commit / push すれば反映されます。
